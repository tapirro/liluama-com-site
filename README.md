# Liluama

> Enciclopedia de plantas medicinales andinas con más de 250 especies documentadas y herramienta de interacciones.

**[Visitar liluama.com](https://liluama.com)**

## Sobre este proyecto

Este repositorio contiene el sitio web de [Liluama](https://liluama.com), un recurso de salud basado en evidencia científica enfocado en **Enciclopedia Botánica**.

### Ingredientes clave

Base de datos: 250+ plantas medicinales andinas y amazónicas con usos, evidencia clínica e interacciones

## Tecnología

- HTML5 + CSS3 (sitio estático)
- Hospedado en GitHub Pages
- Sin dependencias de JavaScript frameworks
- Optimizado para Core Web Vitals

## Evidencia científica

Todo el contenido está respaldado por:
- Estudios clínicos publicados en PubMed
- Monografías de la EMA (European Medicines Agency)
- Guías de la OMS sobre plantas medicinales
- Base de datos TRAMIL de plantas del Caribe y Latinoamérica
